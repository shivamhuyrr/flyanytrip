# ✈️ FlyAnyTrip — Book Cheap Flights Worldwide

A modern, responsive flight booking homepage for **FlyAnyTrip** — an authorized ticketing partner of Trip.com.

## 🌐 Live Site

**[flyanytrip.vercel.app](https://flyanytrip.vercel.app)**

## ✨ Features

- 🔍 Flight search with One Way, Round Trip & Multi-City tabs
- 👥 Passenger picker with Adults, Children & Infants
- 🔥 Trending flight deals section
- 🌍 Popular international destinations gallery
- 💬 Customer testimonials
- 📱 App download section with phone mockup
- ❓ FAQ accordion
- ✉️ Newsletter subscription
- 📊 Animated statistics counter
- 🎨 Scroll reveal animations

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** — No frameworks or dependencies
- **Google Fonts** — Inter & Outfit

## 📁 Project Structure

```
├── index.html      # Main page
├── style.css       # All styles
├── script.js       # Interactive features
└── images/         # Destination & airline assets
```

## 🚀 Getting Started

Just open `index.html` in a browser, or serve locally:

```bash
npx serve .
```
